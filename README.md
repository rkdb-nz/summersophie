# SummerSophie

A 25-door advent puzzle calendar for Sophie, 1–25 December 2026.

## Cloudflare Pages

Connect this repository, select branch `main`, leave build command empty, and set build output directory to `dist`.

Preview all doors with `?preview=1`. The normal URL unlocks one door per day in Pacific/Auckland time. Progress is saved in the current browser. Preview progress is separate.

Static HTML/CSS/JavaScript; no dependencies or build required. Suitable puzzles and four images are reused from Fiona Hunt 2026; romantic text and personal videos are excluded.
